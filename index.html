01 colours

Primary
Lime Cream (--colour-primary) is the main accent colour for the site. It is used for buttons, links, and other interactive elements.
Text & Background
--colour-text and --colour-background have their own selection of tints and shades.
Semantic Colours

Semantic colours are used throughout the site to indicate meaning and context. Danger, success, warning, and info.

02 buttons

Buttons have various styles and states. Default is the primary button with slightly rounded corners.
Secondary, danger, outline, and ghost buttons are also available.

Style Class Default Disabled
Primary
Secondary .secondary
Danger .danger
Outline .outline
Ghost .ghost

Buttons can also have SVG icons alone, or on the left or right side. The icon should automatically adjust to the button size. The path element fills with currentColor to match the button text color.

Icon only buttons need the .icon class to remove the default padding and center the icon.

Style Class Default Disabled
Icon Only .icon
Icon Left
Icon Right

Different corner styles can combine with the different button variants.
Classes of .tl, .tr, .bl, and .br can be used to adjust the corners.

Top Right .tr
Bottom Left .bl
Bottom Right .br
Button Group
.button-group
